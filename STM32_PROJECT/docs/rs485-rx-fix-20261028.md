# RS485 PING无回复：接收路径修复（2026-10-28）

板上复现：初始化完成，成功接收计数1，USART1 ISR=0x006000D8（ORE置位），CR1=0x0D，BRR=139，PB4低。原零超时HAL接收会在检查ORE前返回超时，软件错误计数为0并不能证明无硬件错误。主循环逐字节收取且无接收缓存，无法保障连续115200波特字节不丢失。
