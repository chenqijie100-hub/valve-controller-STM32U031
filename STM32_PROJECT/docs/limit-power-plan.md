# 自动限位供电管理实施计划

目标：在已验收3B和ADC修复基础上，自动关闭空闲限位上拉，动作前非阻塞恢复，保持断线最高优先。用户2026-10-29的完整规格是本计划依据；用户授权实施、测试、独立本地提交，不Push。

基线：c2c61a5。当前未提交power_config.h默认2及main.c强制PA2高的临时测流修改，原件/补丁已保存在工作区tmp/limit-power-baseline。模式2不覆盖、不并入新提交；强制高测试将由本任务授权的自动管理替代，基线及测流快照保留。

设计决定：
- 新增独立limit_power.c/h，阶段UNINITIALIZED/SETTLING/READY/OFF；仅Stop1配置2自动断电，0/1保持检测供电，方便调试对比。
- 集中配置重新使能稳定100ms、到位有效输入确认100ms；前者沿用当前上电100ms等待经验，均须示波器板测，不视为RC最小值保证。保持现有上电等待和电机20ms/2ms/2000ms时序。
- ValveInputs新增limits_invalid（默认0兼容原测试）。统一ValvePort_Read过滤：OFF/SETTLING时返回最后有效限位副本并标记无效，不能用于双限位、到位完成或启动；L4/L5/nFAULT/粘滞断线事件保持实时。STATUS增加有效标志区分实时与缓存。
- Valve_Step先处理断线、恢复授权和控制消抖，再处理有效限位。无效时不驱动/不确认到位；异常在运动中失效则停机、位置未知。全部底层REFERENCE/WAKE/RUN入口再检查检测电路有效，FAULTCLR必须读到有效输入。
- 主安全服务处理L4后才调用限位供电服务：OFF遇到L4/L5边沿、事件代数变化、安全任务、手动请求、未知位置/故障或其他待处理动作立即恢复供电，等待100ms期间电机禁止动作且禁止休眠。有效后用新实测输入决策，不用旧缓存完成安全关阀。
- 仅READY、实际驱动关闭、阀门OPENED/CLOSED、对应单限位有效稳定100ms、控制状态稳定、无故障/无安全任务时关闭。关断前短PRIMASK临界区重新核对事件代数、L4/L5/限位原始电平、EXTI/粘滞事件和安全输出。先标无效再PA2高，晚到事件不清除，下一安全服务恢复检测。
- power_manager与power_port GPIO签名统一：无效时屏蔽L1/L2、使用无效标记；仍实时比较L4/L5/代数/pending。SETTLING阻止WFI，OFF允许原Stop1流程，不能因断电后假双限位而持续唤醒或误报。
- 外部强行改变阀位但未触发L4/L5时，OFF只能保留最后确认位置；本阶段无周期位置检查，状态快照必须标示限位无效，不能声称持续检测。故障/未知默认检测供电有效。

任务：
1. 测试先行：新增独立模块用例（使能/确认/关断/缓存/事件/竞态/故障/回绕），控制器无效输入用例，底层启动门禁，Stop与完整应用复验。
2. 实现模块、最小有效性门禁、main集成、快照诊断、构建链接，不动ADC换算/RTC时基/驱动方向/PWM/换向常量。
3. 全部主机模拟+三配置干净构建；独立只读复核，修复实质问题。
4. 列出修改清单、保存基线及独立本地提交，给出PA2/L1/L2电平与稳定波形、100次唤醒/断线/恢复、目标电流约52.57uA的实机复验。完成后停止。
