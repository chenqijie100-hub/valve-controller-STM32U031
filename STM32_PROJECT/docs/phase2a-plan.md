# Phase 2A implementation plan (2026-10-28)

Scope: user-authorized ADC battery detection + read-only unified status snapshot. User clarified 2B is deferred. Preserve valve_control, valve_port, RX IRQ, PH/PWM/timing/recovery; no timeout enforcement, battery %, RTOS, STOP mode, current thresholds, CRC/protocol work or Push.

Baseline: Git unborn master, all project files untracked. 67 executable scenarios pass. Source/config snapshot and hashes saved in ../../tmp/phase2a-baseline-20261028 before editing. Create local baseline commit and separate 2A commit when Git metadata access permits; do not stage generated artifacts or unrelated user files.

Architecture: battery_monitor.c owns periodic nonblocking acquisition and last-good/filter metadata; battery_adc_port.c is the sole HAL ADC adapter. Sample BAT rank1, MOTOR rank2, VREFINT rank3. Retain existing mV ratio using 64-bit integer arithmetic; estimate VDDA from factory VREFINT at 3000mV. Invalid calibration/reference/range/partial sequence never publishes fresh values. No silent fixed-VDDA fallback. Four-sample rolling mean of compensated battery mV, reset window after a failed attempt; retain last-good voltage/update tick and a separate latest-attempt result. Age >1000ms invalidates data even if last attempt succeeded.

Read schematic: R17=1.5Mohm, R19=680kohm, C20=100nF gives Rth~468kohm and tau~46.8ms. ADC1_MOTOR comes from IPROPI, R15=3.3kohm and C18=10nF; keep raw only. Change ADC clock16MHz/div4=4MHz and sampling160.5cycles=40.125us (was4.969us). Wait500ms before first acquisition (cooperatively), sample every250ms. One conversion per service call, zero wait for EOC; per-sequence20ms deadline; HAL start/stop are strictly bounded by existing2ms subroutine timeouts (fault path stop+disable may total~6ms incl tick quantization), EXTI remains enabled. ADC stuck-stop recovery failure is latched unavailable until re-init rather than repeated blocking every cycle.

Snapshot: app_status.c stores a copied snapshot after each main-context safety step; getter returns a copy and computes battery age/validity without consuming EXTI events, GPIO rereads or modifying valve state. Capture both raw wire and qualified current faults, limits, mode, driver, fault sets and complete battery metadata. All getters are main-context only; IRQ never touches snapshot. STATUS uses one copied snapshot and never starts or waits for ADC. Service ADC at most once per control service, after the safety step, including TX waits. Full snapshot publication occurs after ADC service so queried metadata is coherent at capture time.

Tests before implementation: battery arithmetic/VDDA/filter/failures/partial sequence/deadline/calibration/staleness/rollover; HAL adapter calls and bounded error paths; snapshot raw vs qualified state/copy isolation/age/no event consumption; real application STATUS cached validity and motor safety during ADC failure + all67 phase1 cases. Clean Debug build and independent review. Board acceptance: DMM comparison, high-impedance probe loading, startupRC/ripple/step response, motor load/repeated queries, injected sample failure on simulator only. No blockage testing.

Timeout recommendation only: optional separate open/close configured maxima with zero=disabled, elapsed measured from PWM activation, protection collection before arrival, existing TIMEOUT bit + SAFE_INCOMPLETE for failed safety close. Need measured worst-case travel and safe mechanical limits before enabling; no change this phase.
