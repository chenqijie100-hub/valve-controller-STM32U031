# Stage 3A: Sleep framework (2026-10-28)

The detailed user request authorizes implementation. Only ordinary Sleep; Stop1/2/Standby, RTC wake timers, UART stop-wake features and LIMIT_EN switching are excluded. Preserve motion direction, PWM, timing, wire-break close and recovery interlock. Scope is not a protocol redesign.

Baseline: Git unborn, project untracked; pre-edit1270 source/config files and hashes in ../../tmp/phase3a-baseline-20261028,99 executable scenarios passed. Local baseline and feature commits requested, noPush. Existing .git ownership differs across sandbox/escalated users; safe.directory is restricted to the exact workspace per command, never global.

Design: default POWER_LOW_POWER_MODE=0 keeps ASCII debug fully active and never sleeps. Mode1 uses independent TIM2 32-bit counter at1kHz as monotonic HAL_GetTick source (same49.7-day wrap), freeing SysTick from waking CPU every1ms during Sleep. TIM2 compare interrupt wakes only for next background ADC deadline, capped250ms. TIM2 is an internal counter/compare, no GPIO, ordinary APB Sleep clock retained; RTC and UART low-power wake configuration remain unchanged. Before PowerPort_Init, HAL_GetTick falls back to uwTick. Unsupported clock or pre-owned TIM2 disables Sleep and retains original timebase. This is not a Stop-compatible timebase.

Read-only module queries expose valve idle eligibility (including preparation, cooldown with pending request, debounce, wire release qualification, rearm-low qualification and manual request), ADC work/deadline, UART queued/error/partial-command work. All conditions must pass; unfinished safe-close always blocks, even if protected fault prevents progress. GPIO interrupts still immediately cut opening, record events; both edges PA3/PB0 increment a generation counter. Main records generation BEFORE safety sampling and marks it processed AFTER safety/ADC service. Compare processed/current generation, raw PA3/PB0/limits signature, sticky wire event, EXTI/NVIC/UART pending, outputs asleep and modules ready again under a short PRIMASK critical section before HAL_PWR_EnterSLEEPMode(PWR_MAINREGULATOR_ON,PWR_SLEEPENTRY_WFI). Pending IRQ between final test and WFI wakes masked WFI; restore SysTick before unmasking. Next main iteration rereads actual GPIO and prioritizes safety before UART. HAL_Delay or TX never executes while SysTick suspended; always restore on wake/abort. Time does not freeze because TIM2 continues in Sleep.

TIM2 is reserved for PM; PWM TIM1 untouched. LIMIT_EN stays low. Debugger may distort Sleep current; accept mode1 only after standalone GPIO/race/timebase/ADC/serial tests. Ordinary USART RX IRQ can wake ordinary Sleep with clocks retained, but no promise about Stop UART reception and no special USART wake API enabled.
